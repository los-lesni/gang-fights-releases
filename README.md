# Gang Fights - releases

Downloads for **Gang Fights**, an online brawler built on the game files of *The Warriors* (PlayStation 2).

This repository only holds the released programs. It contains no data from *The Warriors*: Gang Fights makes its game files on your PC, from your own copy of the PS2 game (USA, SLUS-21215).

## Install

1. Download `GangFights-alpha.zip` from the latest alpha release and unzip it into an empty folder. Gang Fights is in alpha: expect missing features and rough edges.
2. Open `GangFights.exe`. The first time, Windows may say "Windows protected your PC": choose *More info* > *Run anyway*.
3. The first time, the game asks for your ISO of The Warriors (PS2, USA) and a folder for its files (about 4.5 GB).

`GangFights.exe` keeps the game up to date, and installs an update only if it is signed by the Gang Fights team.
